# Screenshot samples

The four JPEGs are full-frame captures of PickPic v0.4.0 JavaScript running
in an existing Android API 37 development build (1080 × 2424). The native
APK has not been rebuilt for this source-version update. No UI was composited
or replaced; JPEG export only reduces repository size.

The sample library belongs to a separate demo profile. No personal photos,
private paths, database snapshots, or development error overlays are included.
The three sample photos were generated with the built-in imagegen tool;
they are illustrative material, not an AI-accuracy benchmark.

Prompt set (photorealistic-natural; each is a single 3:4 portrait photo):

- Lake: a quiet alpine lake, turquoise water, forest foreground and distant
  mountain peaks in soft morning light; realistic understated colors and
  believable smartphone photography, detailed but not oversharpened.
- Cat: an orange and white cat resting by a sunlit apartment window beside
  a small houseplant; tactile fur, calm composition and soft ordinary daylight.
- Coffee: a ceramic cappuccino and croissant on a dark wooden table near
  a window, linen napkin, soft side daylight and restrained brown/cream colors.

All three prompts exclude people, text, logos, borders, collages, app UI
and watermarks. Original generated samples and diagnostic captures stay
outside the Git repository; only the four selected screenshots are published.
